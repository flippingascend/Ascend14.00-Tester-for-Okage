STEP 1 - DNS BLOCKER (optional, independent of the loader)
----------------------------------------------------------
This blocks PSN on the PS5. It has nothing to do with the ELF loader.

  Right-click RUN_DNS.bat > Run as administrator.

It self-elevates, finds Python, and prints your PC IP.
Port 53 needs administrator rights. Leave the window open.


STEP 2 - POINT THE PS5 AT YOUR PC
----------------------------------
PS5 > Settings > Network > Set Up Internet Connection > your WiFi > Custom:

  IP Address Settings: Automatic
  DNS Settings:        Manual
  Primary DNS:         192.168.0.189   <-- your PC IP
  Secondary DNS:       192.168.0.189   <-- same, so PS5 cannot bypass blocker
  MTU:                 Automatic
  Proxy Server:        Do Not Use

Using the same IP for both forces all DNS through your PC.
If the PS5 is on DHCP DNS the blocker sees nothing - it must be Manual.

TROUBLESHOOTING
---------------
DNS blocker says "port already in use":
  Something else holds port 53 (usually the Windows DNS Client service).
  Win+R > services.msc > DNS Client > stop it, set to Manual, retry.

PS5 still reaches PSN despite the blocker:
  Secondary DNS is bypassing. Both primary AND secondary must be
  192.168.0.189, and DNS Settings must be Manual.

send_elf.bat reports connect failed:
  - The Stage 2 save must be loaded, not the Stage 1 lightbar save.
  - The loader only listens after the game has exited to the home screen.
  - PC and console on the same LAN, no AP client isolation.
  - Allow Python through Windows Firewall if prompted.

Save shows Corrupted:
  The bot did not resign correctly. Redo Step 3.
